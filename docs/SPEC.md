# よりしろ — 仕様

『月蝕綺譚』の御霊を、カメラごしに机の上へ小さく呼び出して写真に残す道具。
**ゲームではない**（夜じたてと同じ枠。腕前・スコアの勝ち筋は使わない）。

芯: **いまカメラが映している場所を「依代」にする。**

---

## §1 画面

縦一列の2段。上が**場**、下が**帳**。

| 段 | 中身 |
|---|---|
| 場 | カメラ映像（`object-fit:cover`）／その上に御霊（透過の `<model-viewer>`）／左上に名札・右上に ≡ |
| 帳 | ①御霊の横スクロール（14柱）②しぐさ3つ＋丈 ③カメラ・一枚撮る・机に置く |

カメラを許す前は、映像の代わりに**宵闇の地**（`#131320` ↔ `#1B1B2E` の放射）を敷く。
**開いた時点で御霊は立っている**（何も押していなくても、道具が何をするものか分かる形）。

## §2 御霊（14柱）

素材蔵の `model3d`（ゲーム版GLB・骨としぐさ付き）に在る14柱をそのまま名簿にする。

栞／餡音／於兎／ネム／エマ／シャオラン／カルマ／アトザ／アウン／オロチ／柴／石舟斎／サスラ／トバリ

- 名簿は `index.template.html` の `MITAMA` 表（MCP `list_assets(kind=model3d)` と `list_spirits` の写し）
- **実行時に素材蔵から読む。原本は持たない**（`Access-Control-Allow-Origin: *` を確認済み）
- 取り込んだ GLB は `kura` の Map に控える（**丈を変えても取り直さない**）
- 14柱とも `idle` / `bow` / `nod` の3つのしぐさを持ち、圧縮拡張（Draco・KTX2）は無い（2026-09-04 実測）
- 背丈は 1.885〜1.901m。**1.9m を素の丈として扱う**

## §3 しぐさ

`佇む`(idle) / `辞儀`(bow) / `頷く`(nod)。押すと `animation-name` を差し替え、`currentTime=0` から流す。
御霊を替えたときは `idle` に戻す。

## §4 丈（たけ）

**15 / 20 / 30cm** の三択。釦を押すたびに巡る。既定は 20cm。`localStorage` に控える。

### 当て方

GLB の JSON 区画を読み、**場面の根をまとめて包む「拡縮の節」を1つ足す**。

```
scenes[0].nodes = [新しい節]
新しい節 = { scale:[s,s,s], children:[もとの根…] }
s = (丈cm / 100) / 1.9
```

**骨（joint）も同じ節の下に入るので、皮つきのモデルでも丈が正しく効く。**
（mesh の節だけを縮めても、皮つきでは効かない——glTF は皮つきの mesh 節の変換を無視する）

JSON区画は4バイト境界まで空白（`0x20`）で、BIN区画は `0x00` で詰め直す。

### なぜ丈が要るか

端末のARは**実寸**で置く。素のモデルは 1.9m ＝ 等身大なので、そのまま渡すと**人の大きさで
部屋に立つ**。置物にするには GLB 自体を縮める必要がある。
`ar-scale="fixed"` はモデルの単位をそのままメートルとして扱う。

## §5 見え方

| 項目 | 値 | 理由 |
|---|---|---|
| `camera-orbit` | `10deg 75deg 180%` | 75度＝水平から15度見下ろす。机を見る目の高さ。**距離は割合で書く**——絶対値（`0.75m`）だと既定の `max-camera-orbit` に切り詰められる（実測0.456m・画角も28°→32.09°に丸められた）。割合なら丈を変えても見え方の比が保たれる |
| `min/max-camera-orbit` | 距離 `60%` 〜 `500%` | つまみで寄る／引く幅。既定のままだと 180% すら許されない |
| 既定の差し口 | `ar-button` / `progress-bar` を空スロットで塞ぐ | 塞がないと model-viewer が英語の錠剤型ARボタンと進捗バーを出す。**`canActivateAR` が真のときだけ＝実機でだけ現れる** |
| `shadow-intensity` | `1.15` / softness `0.7` | **机に載って見えるのはこの接地影のおかげ。**平面認識はしていない |
| `environment-image` | `neutral`（内蔵） | 外部を取りに行かない |

**平面認識はしない。**WebXR の `immersive-ar` は iOS Safari に無い（2026-09-04 実機確認）。
本当に平面へ置きたいときは §6 に渡す。

**この画面は「覗き窓」だと言い切る（2026-09-04 オーナー裁定）。**端末を動かすと御霊は
付いてくる。傾き（ジャイロ）で留める案は**見送り**——歩いて近寄るとズレる中途半端さが残るうえ、
実機でしか合わせられない。**代わりに画面と手引きの言い方を改めて、できないことを
できるように見せかけない。**

## §6 机に置く（端末のAR）

`ar ar-modes="webxr scene-viewer quick-look" ar-scale="fixed"`。
`canActivateAR` が偽なら、その旨を告げて何もしない。

- iOS = AR Quick Look（GLB から USDZ を model-viewer が実行時に変換）
- Android = Scene Viewer
- そちらは**この道具の画面ではない**ので、しぐさの切り替えはできない
- **AR Quick Look は「オブジェクト」表示で開くことがある**（2026-09-04 実機）。
  画面上部の「AR」に切り替えないとカメラが開かない。**渡す前に道しるべの札（`#shirube`）で
  それを伝える。**「次からは出さずに、すぐARへ渡す」を押したら `localStorage` に控えて省く

## §6.5 撮影の口はひとつ（2026-09-04 実機 AbortError）

**iOS は撮影の口をひとつしか開けない。**頁がカメラを掴んだまま別の画面（ARなど）へ渡すと、
向こうもカメラを使うので取り合いになり、戻ってきたときに **`AbortError`** で開けなくなる。
**自分で自分を塞いでいる状態。**

- **手放す**: `visibilitychange`（裏に回る）・`pagehide`・**ARへ渡す直前**に必ず
  `track.stop()` して `srcObject = null`。表に戻ったら、掴んでいたときだけ開き直す
- **試し直す**: `getUserMedia` は3段の制約で順に試し、あいだに500ms待つ
  （`environment`＋1920 → `environment` のみ → `video:true`）。
  `NotAllowedError` だけは待っても変わらないので即座に諦める
- **人の指からしか呼ばない**: iOS はタップ以外からのカメラ要求を黙って止め、
  `getUserMedia` の約束が**返ってこない**。裏から戻ったときに自動で開き直してはいけない
  （告げるだけにして、次の一手は人に委ねる）
- **8秒の見切り**（`machi()`）: 約束が返らなくても釦を元に戻す。`TimeoutError` は
  `NotAllowedError` と同じ扱い
- **拒まれたら札を出す**（`#kobami`）: 「ぁあ」→ Webサイトの設定 → カメラ → 許可 →
  読み込み直す の4手。**手順は告げ札（トースト）では渡せない**
- **言い分を分ける**: `NotAllowedError`／`TimeoutError` は札・
  `AbortError`/`NotReadableError` は「**他で使われています。別のタブやアプリを閉じて**」。
  この2つは原因が別なので、同じ文言にしない

## §7 一枚撮る

1. 場の寸法 × `devicePixelRatio`（上限2）の canvas を用意し、地を `#131320` で塗る
2. カメラ映像を `cover` の算術で敷く
3. `mv.toDataURL('image/png')`（透過）を同じ矩形に重ねる
4. JPEG 品質0.92 で Blob にする

渡し方は2段構え:

- `navigator.canShare({files})` が通れば **Web Share**（iOS はここから「画像を保存」）
- 通らなければ `<a download>`
- どちらも案内文に「**長押しして写真に保存**」を併記する（iOS の確実な逃げ道）

## §8 守るもの

- `charset` は先頭・`viewport-fit=cover`・`env(safe-area-inset-*)`
- iOS のダブルタップ拡大と `gesturestart` を抑止する。**ただし `model-viewer` の上では抑止しない**
  （つまんで寄る操作を殺さないため）
- `localStorage` は try/catch
- `X-Frame-Options` は付けない
- 文字は12px未満を使わない／押し所は48px以上／角丸は 4・5・10px／色は `data/design-tokens.json` の系
- 外部スクリプトの参照は**0件**（`model-viewer` は `scripts/build.mjs` が sha256 を照合して畳み込む）

## §9 出さない場所

**わいわいタウンには出さない。**掲載ページは Pages を iframe で読むが、
枠が `allow="camera"` を渡さないとカメラが動かない（`videoinput` が0台になる）。
夜じたてと同じく **Pages のみ**。

## §10 やらないと決めたこと

| 見送り | 理由 |
|---|---|
| 平面認識（WebXR） | iPhone で動かない＝客の半分が遊べない。端末のARに渡すほうが確実 |
| 複数の御霊を同時に立てる | 画面が混む。まず一柱で反応を見る |
| 背景の合成・切り抜き | 「その場に居る」が芯。景色を作り替えると別の道具になる |
| 番付・スコア | ゲームではない（会社ノート「ゲーム以外も作る」） |
