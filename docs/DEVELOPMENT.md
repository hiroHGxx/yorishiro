# よりしろ — 制作記録

同じ穴を2度踏まないための記録。日付は踏んだ日。

## 2026-09-04 第1便

### 素材が1日で覆った

同日の朝の見立ては「サークルに3Dモデルは1体も無い」だった。同日 `kitan-lore` に
`model3d`（御霊のゲーム版GLB・骨としぐさ付き）14体と `model3d_hi`（高解像度・骨なし）が
入っていた。**「無い」にも賞味期限がある。**素材の在庫は企画のたびに取り直す。

### 取り込む前に GLB の中を測った

14柱すべてについて、しぐさ（`idle`/`bow`/`nod`）・`extensionsUsed`・背丈を先に測った。

**圧縮拡張（Draco・KTX2）が入っていたら、復号器を外部から取りに行く経路が増える。**
今回は14柱とも拡張なし・背丈 1.885〜1.901m で揃っていたので、`1.9m` を素の丈として扱えた。

### 丈は GLB の側で当てる（皮つきの落とし穴）

端末のARは実寸で置くので、素のまま渡すと**等身大（1.9m）で部屋に立つ**。

縮めるとき、**mesh の節だけを縮めても効かない**——glTF は皮つき（skinned）mesh の
節の変換を無視し、骨（joint）の世界変換で形が決まるため。
**場面の根をまとめて包む節を1つ足し、mesh も骨も同じ節の下に入れる**のが正しい。

実測: 丈15/20/30cm を選ぶと `getDimensions().y` が **0.15 / 0.20 / 0.30** ちょうどになる。

### 距離を絶対値で指定すると切り詰められる

`camera-orbit="… 0.75m"` と書いたのに、実測は **0.4556m**・画角も 28°→32.09° に
なっていた。model-viewer は既定の `max-camera-orbit` で距離を丸める。

**丈が変わる作りでは、距離は割合（`180%`）で指定する。**割合なら model-viewer の
自動の枠取りを基準にするので、丈を変えても見え方の比が保たれる。
つまみの幅は `min-camera-orbit`/`max-camera-orbit` を `60%`〜`500%` で開けておく。

### 金地に金の字

「佇む」の字が消えていた。原因は CSS の優先順位:

```
.oshi.kin{background:金泥高; color:金地の上の文字}      ← 先
.oshi[aria-pressed="true"]{color:金泥高}                ← 後・同じ強さ
```

同じ強さなら後ろが勝つので、**金地に金の字**になった。
`.kin` と `[aria-pressed]` の二重管理をやめ、選択状態は `[aria-pressed]` だけで表す。

### model-viewer の既定の差し口は塞ぐ

`ar` を付けると、model-viewer が**自前の英語のARボタン（白い錠剤型・角丸100px）**と
**進捗バー**を出す。ヘッドレスでは `canActivateAR` が偽なので**出ず、実機でだけ出る**。

```html
<button slot="ar-button" hidden></button>
<div slot="progress-bar" hidden></div>
```

### 実機（2026-09-04 22:02・iPhone / Safari）— カメラが開かない `AbortError`

URL欄に**緑のカメラ印が出たまま** `AbortError`。**掴まれたままだった。**

原因は自分の作り。**ARへ渡すとき（`activateAR`）にカメラを手放していなかった。**
AR Quick Look も同じ撮影の口を使うので取り合いになり、戻ってきても掴めない。
裏に回ったとき（`visibilitychange`）・頁を離れるとき（`pagehide`）も同じ。

- `visibilitychange` / `pagehide` / **ARへ渡す直前**に `track.stop()` して手放す。
  表に戻ったら、掴んでいたときだけ静かに開き直す
- `getUserMedia` は3段の制約で500ms空けて試し直す（`NotAllowedError` だけは即諦める）
- **`AbortError` と `NotAllowedError` で言い分を分ける**——原因が別なのに同じ文言にすると、
  設定を見に行っても直らない

**教訓: 端末の資源（カメラ・マイク）を握る画面は、「開ける」と同じ重さで「手放す」を書く。**
握りっぱなしの相手が自分自身だと、いちばん気づきにくい。

### 実機（2026-09-04 22:34）— 釦が「問いかけ中…」で固まる／カメラが「拒否」に

**前の手当てで入れた「戻ったら自動で開き直す」が、そのまま原因だった。**

- **iOS はタップ以外から呼んだカメラ要求を黙って止める。**問いかけが出せない状況では
  `getUserMedia` の約束が**解決も拒否もされないまま返ってこない**。だから釦が
  「問いかけ中…」のまま固まり、`catch` にも入らない。
- しかもその要求が重なると、Safari 側でこの頁のカメラが**「拒否」**として覚えられる
  （アドレス欄のカメラ印に斜線が入る）。**良かれと思って足した自動再開が、
  頁を自分で壊していた。**

直し:

1. **自動で開き直すのをやめた。**戻ったときは告げるだけ（「カメラを許す」でまた開けます）。
   **カメラ・マイクの要求は、必ず人の指から始める。**
2. **8秒の見切りを入れた**（`machi()`）。約束が返らなくても釦は元に戻る。
   `TimeoutError` は `NotAllowedError` と同じ扱い（待っても変わらない）。
3. **「拒まれています」の札を出す**（`#kobami`）——アドレス欄の「ぁあ」→ Webサイトの設定 →
   カメラ → 許可 → 読み込み直す、の4手。告げ札（トースト）では手順を渡せない。
   カメラ無しでも御霊を眺める・丈を変える・**机に置く**は使えることも書いた。

**教訓: 自動化を1つ足すたびに「これは人の指なしで呼ばれるか」を数える。**
端末の資源を握る呼び出しは、そこに置いてはいけない。

検分（ヘッドレスで両方の筋を通した）:

| 筋 | 結果 |
|---|---|
| `NotAllowedError` を返す | 札が出る・釦は「カメラを許す」に戻る |
| 永久に返らない約束 | 8秒で札が出る・釦は戻る（**固まらない**） |

### 2: 帯は、USDZを焼かなくても出せた

model-viewer の実装を読むと、**`ios-src` が無いとき `src` の `#` を Quick Look の URL へ写す**
（`t.hash && (i.hash = t.hash)`）。`blob:` の URL に `#` を付けても模型の読み込みには
影響しないことを実測したので、**`mv.src = blobURL + "#checkoutTitle=…"` だけで帯が出る**。

事前に焼く道（42ファイル・**実測 53MB**）と three.js の同梱（+1MB）を両方回避できた。
**ライブラリの実装を読むと、積まずに済む道が見つかることがある。**

### 3: 姿を焼く必要は無かった

USDZ は骨を持てないので束ね姿で出る。だが**束ね姿と `idle` の t=0 の差は
最大 1.7cm／1.9m ＝ 0.9%**（エマ0.81% 栞0.87% カルマ0.90%）。丈20cmでは **1.8mm**。

**やる前に測ったから落とせた。**代償（53MB＋1MB）は見えない差には見合わない。
**「やったほうが良さそう」を、やる前に数字にする。**
