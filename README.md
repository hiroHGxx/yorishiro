# よりしろ

『月蝕綺譚 -Luna Occulta-』の御霊を、**カメラごしに机の上へ小さく呼び出して、写真に残す**道具。

**御霊が宿る器を「依代」といいます。この道具では、いまカメラが映している場所がその器になります。**

**https://hirohgxx.github.io/yorishiro/**

---

## これは何をするか

1. **カメラを許す**を押す（端末が問いかけてきます）
2. 机や棚にカメラを向ける
3. 下の列から御霊を選ぶ（**14柱**）
4. 指でなぞると向きが変わり、つまむと寄れます
5. **一枚撮る**で、カメラの絵と御霊を重ねた一枚を写真に残せます

しぐさは **佇む・辞儀・頷く** の3つ。丈（背丈）は **15 / 20 / 30cm** から選べます。

## この画面は「覗き窓」です

御霊は**画面に留まります**。端末を動かすと一緒に付いてきます——机を認識してそこへ
固定しているのではなく、カメラの絵に重ねているだけだからです。
**向けて・指で合わせて・撮る**ための窓として作ってあります。

**本当にその場へ固定したいときは「机に置く」**（§端末のAR）。

## 平面認識はしていません

**この道具は机を認識していません。**それでも机に載って見えるのは、
model-viewer が落とす**接地影**と、端末を構える人の視線のおかげです。

「本物の平面認識」は WebXR（`immersive-ar`）の仕事ですが、
**iOS Safari には現在 `navigator.xr` がありません**（2026-09-04 に実機で確認）。
Android Chrome にはあります。

そのかわり **机に置く** の釦を押すと、端末に元から入っているAR
（iOS = AR Quick Look / Android = Scene Viewer）へ渡します。
そちらは本当に平面を探して、歩き回っても同じ場所に立ち続けます。
**この道具の画面ではなくなる**ので、しぐさの切り替えはできません。

### 開いたら「AR」に切り替える（2026-09-04 実機で判明）

AR Quick Look は **「オブジェクト」（白い部屋で眺める表示）で開くことがある。**
画面の上の **「AR」** に切り替えるとカメラが開き、床や机に置ける。

これを知らないと「ARが動かない」に見えるので、**渡す前に道しるべの札を出す**
（`#shirube`）。「次からは出さずに、すぐARへ渡す」を押すと以後は省く（`localStorage`）。

### 丈は AR でもそのまま使われます

端末のARは**実寸**で置きます。素の3Dモデルは背丈が 1.9m（＝等身大）なので、
そのまま渡すと**人間の大きさで部屋に立ちます**。

この道具は GLB の場面の根に「拡縮の節」を1つ足してから渡すので、
選んだ丈（15/20/30cm）の**置物の大きさ**で現れます。
骨（joint）も同じ節の下に入るため、皮つきのモデルでも丈が正しく効きます。

## 素材

**原本は1つも入っていません。**
素材蔵（`https://kura.vibe.co.jp/`）が `Access-Control-Allow-Origin: *` を返すため、
ブラウザが実行時に直接読み込んでいます。

| 出どころ | 使っているもの |
|---|---|
| 公式配布（素材蔵 `kura.vibe.co.jp`） | 御霊の3Dモデル 14体（`model3d`・GLB・骨としぐさ付き／**3Dフィギュア＝シャックさん作**）。実行時に読み込む |
| 自作 | 画面・丈の当て方・カメラとの重ね方・写真の組み立て |

14柱すべて **`idle` / `bow` / `nod` の3つのしぐさ**を持ち、圧縮拡張（Draco・KTX2）を
**使っていない**ことを取り込み前に確認しています（使っていると、復号器を外部から
取りに行く経路が増えるため）。

名簿（どの御霊がどのファイルか）は公式MCP `kitan-lore` の
`list_assets(kind=model3d)` と `list_spirits` の写しで、`index.template.html` の
`MITAMA` 表に焼いてあります。

## 開発

単一の `index.html`。**外部スクリプトの参照は0件**です（`model-viewer` は畳み込んであります）。
手で編むのは `index.template.html` のほうで、`index.html` は焼いた結果です。

```
node scripts/build.mjs      # index.template.html + model-viewer → index.html
```

`build.mjs` は model-viewer 4.3.1 を版を固定して取り寄せ、**sha256 を照合してから**畳み込みます
（中身が変わっていたら止まります）。取り寄せた控えは `scripts/model-viewer-4.3.1.min.js` に
残りますが、git には入れていません（同じ中身が `index.html` にも入るため）。

### 実機で確かめること

- **カメラは https でしか動きません。**ローカルのファイルを開いても、LAN 経由でも通りません。
  GitHub Pages に載せた状態で確かめてください。
- **iframe の中でも動きません。**枠が `allow="camera"` を渡さないと
  `enumerateDevices()` の `videoinput` が0台になり、`getUserMedia` は
  `NotAllowedError` を返します（この文面は「本人が許可しなかった」ときと同一なので、
  切り分けるには台数を数えます）。**わいわいタウンには出しません。**
